Exposes selected cameras to the Apple Home app as live-view-only HomeKit accessories (no HomeKit Secure Video / encrypted event recording). Streams are started on demand by the Home app, the same way Live view starts a camera's stream when its tile is opened.

HomeKit accessory discovery uses mDNS/Bonjour multicast, which does not work through Docker's default bridge networking. A standalone Docker/Docker Compose deployment must be switched to network_mode: host for pairing to work - see the deployment documentation. This is not currently supported through the Home Assistant add-on.
